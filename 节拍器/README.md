# 自动节拍器 Auto Metronome

放入一首歌，自动识别 **BPM（速度）**、**拍号** 和 **每小节的第一拍**，然后跟着音乐一起打拍子。

- 纯前端网页，打开就能用，不用安装
- 音乐只在你的浏览器里处理，**不会上传**到任何地方
- 没有任何第三方依赖，节拍检测算法完全用 JavaScript 自己实现

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动识别 BPM | 精确到小数点后一位，整首歌拟合得出 |
| 自动识别拍号 | 区分 4/4 和 3/4，并找出强拍（每小节第一拍） |
| 跟随打拍 | 节拍声由音频时钟精确调度，和音乐严格同步；强拍用不同的音 |
| 可视化 | 跳动的拍子指示、波形图上标出每一拍和每个小节，点击波形跳转 |
| 手动修正 | 速度 ×2 / ÷2、切换拍号、前后移动强拍、节拍声 ±10ms 微调 |
| 手动打拍 | 跟着节奏点按钮或按 `T` 键，根据点击频率算出 BPM，节拍器按这个速度打拍子 |
| 三种音色 | 木鱼 / 电子 / 牛铃，可分别调节音乐和节拍声的音量 |

快捷键：`空格` 播放/暂停，`←` `→` 快退/快进 5 秒，`M` 开关节拍声，`T` 手动打拍。

### 手动打拍

不放歌也能用，就是一个普通节拍器：

1. 跟着你心里（或耳边）的节奏，连续点「点我」按钮或按 `T` 键，点 2 下以上就会算出 BPM，点得越多越准。停顿超过 2 秒再点会重新计数。
2. 点「开始打拍」，节拍器就按这个速度响。响的时候再点几下，节拍会对齐到你点击的位置（第一下算第一拍）。
3. 也可以直接输入 BPM，或用 −1 / +1 微调，旁边选拍号。

放了歌时，如果自动识别的速度不对：边播放边跟着点，然后点「用这个速度打这首歌」。程序会按你点的速度重新对齐歌里的鼓点（所以不会越打越偏），你点的第一下会被当作小节的第一拍。

## 使用方法

**直接打开：** 下载本仓库，进入 `节拍器` 文件夹，双击 `index.html` 用浏览器（Chrome / Edge / Firefox / Safari）打开即可。

**在线使用：** 在 GitHub 仓库的 *Settings → Pages* 中，把 Source 设为 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后几分钟就能通过 `https://xiaochuan358.github.io/<仓库名>/节拍器/` 访问。

## 工作原理

算法在 [`js/beat-detector.js`](js/beat-detector.js)，大致分 5 步：

1. **短时傅里叶变换**：把音频（先转成 22050Hz 单声道）切成约 46ms 的小段，算出每段的频谱。
2. **起音强度曲线**：比较相邻两段频谱，能量突然增加的地方（鼓点、拨弦、音符开始）得分高。
3. **估计速度**：对起音曲线做自相关，找出最强的重复周期；用"梳状"打分（周期的 1~4 倍处也要相关）并结合以 120 BPM 为中心的先验，减少"倍速/半速"误判。之后再检查拍点之间和拍点上的强弱，做一次倍速/半速纠正。
4. **节拍跟踪**：用动态规划（Ellis, 2007）在"拍点要落在起音上"和"拍与拍间隔要均匀"之间找最优解，得到每一拍的时间，再做局部拟合让拍点更稳。
5. **拍号与强拍**：比较每一拍的低频起音（底鼓、贝斯）和前后和声变化（换和弦常在小节开头），看它们按 3 拍还是 4 拍循环最明显。

### 局限

- 适合节奏清楚的流行、摇滚、电子、舞曲等。古典、纯人声、自由节奏的音乐可能识别不准。
- 速度有"倍速/半速"歧义（比如 70 和 140 BPM 听起来都对），不满意可以点 ×2 / ÷2。
- 拍号目前只自动区分 4/4 和 3/4，其他拍号可以手动选择。

## 开发

不需要构建，改完刷新浏览器就行。

运行算法测试（需要 [Node.js](https://nodejs.org/)）：

```bash
npm test
```

测试会合成几种不同速度和拍号的鼓点音乐，检查识别出的 BPM、拍号、强拍和每一拍的时间（误差需在 20ms 内）。

```
├── index.html            页面
├── css/style.css         样式（自动适配深色模式和手机）
├── js/beat-detector.js   节拍检测算法（可在浏览器和 Node 中使用）
├── js/app.js             界面、播放和节拍声调度
└── tests/                算法测试
```
